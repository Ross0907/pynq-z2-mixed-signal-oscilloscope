## Manufacturing choice (user-confirmed)

- Manufacturer: JLCPCB; nominal four-layer, 1.6 mm, FR4 Tg135.
- Published reference: **JLC04161H-7628**.
- Fabrication: **standard; impedance-control service NOT ordered**. The named published stack describes the physical reference construction; it does **not** grant guaranteed 50-ohm single-ended or 100-ohm differential impedance, a coupon report, or tight dielectric tolerances.
- Outer nominal copper: 1 oz; inner nominal copper: 0.5 oz. ENIG 1 µin (order target).
- In1.Cu is the broad continuous GND reference plane; In2.Cu is power pours with 431 routed segments in the current final layout.

JLC published 1.6-mm reference, top to bottom (mm): outer copper **0.035** / 7628 prepreg **0.2104** / inner copper **0.0152** / core **1.065** / inner copper **0.0152** / 7628 prepreg **0.2104** / outer copper **0.035**. Nominal conductor/dielectric sum **1.5862 mm**, excluding mask. Published dielectric constant: 7628 prepreg **4.4**, core **4.6**; published solder-mask Dk **3.8**. A 0.010 mm mask each side is *ODB model metadata*, not a measured production thickness; this produces a modeled 1.6062 mm total. FR4 loss tangent 0.02 and zero mask loss tangent in the audit model are *existing ODB assumptions, not published vendor-verified frequency-dependent data*.

Official reference: https://jlcpcb.com/impedance (4-layer / 1.6-mm / 1-oz outer / 0.5-oz inner / JLC04161H-7628).
